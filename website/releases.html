v0.1.0 — 2026-10-05

Initial release. Full changelog in the repo (CHANGELOG.md).

  • 6-channel × 16-step sequencer with mute / solo
  • Per-channel fundsp voices + live editor (wave, note, cutoff, Q, ADSR)
  • Mixer with equal-power pan, soft-clipped master bus
  • Live 2-octave piano, master scope, peak meter
  • Latest stack: cpal 0.18, eframe/egui 0.36, fundsp 0.23, Rust edition 2024

Get it — Linux binary (v0.1.0) or build from source:

git clone https://github.com/canureal/thunder-daw.git
cd thunder-daw
cargo run --release
