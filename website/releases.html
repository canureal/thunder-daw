v0.2.3 LATEST

Double-click setup on all three systems, plus fixes for sample loading on Windows.

Windows

Download the .msi, double-click it, and follow the wizard. It asks about Start Menu and desktop shortcuts. After that, start it from the desktop icon. No terminal needed.

thunder-daw-0.2.3.msi

Mac

Open the .dmg, drag ThunderDAW into Applications, then double-click it there. Works on Intel and Apple Silicon Macs.

ThunderDAW-0.2.3.dmg

Linux

Download the .AppImage, right-click it, allow launching (or run chmod +x once), then double-click it. One file, nothing to install. Terminal users can use the installer script instead:

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/canureal/thunder-daw/releases/download/v0.2.3/thunder-daw-installer.sh | sh
