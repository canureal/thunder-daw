v0.2.5 LATEST

Same program, more computers: alongside the normal builds, every release now ships binaries built against an older C library for older Linux systems (Ubuntu 20.04 and newer, Debian 11 and newer).

Windows

Download the .msi, double-click it, and follow the wizard. It asks about Start Menu and desktop shortcuts. After that, start it from the desktop icon. No terminal needed.

thunder-daw-0.2.5.msi

Mac

Open the .dmg, drag ThunderDAW into Applications, then double-click it there. Works on Intel and Apple Silicon Macs.

ThunderDAW-0.2.5.dmg

Linux

Download the .AppImage, right-click it, allow launching (or run chmod +x once), then double-click it. One file, nothing to install. Terminal users can use the installer script or a plain binary instead:

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/canureal/thunder-daw/releases/download/v0.2.5/thunder-daw-installer.sh | sh

thunder-daw-0.2.5.AppImage Linux binary (.tar.xz)

Older system (Ubuntu 20.04 era, Mint 20, Debian 11)? The normal build needs a newer C library. Use the old-glibc build instead, same program:

old-Linux AppImage old-Linux binary (.tar.xz)

First launch warnings

The app is not signed with Apple or Microsoft, so both systems warn on first run. On Mac, right-click ThunderDAW and choose Open, then confirm. On Windows, click More info in the SmartScreen popup, then Run anyway. You only do this once.
