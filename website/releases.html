v0.2.1 LATEST

Cross-platform installs. Tagged builds now ship Linux, Windows and macOS binaries with installer scripts. The sample browser uses the OS music folder, and file paths work on Windows. Full notes in CHANGELOG.md.

Linux or macOS:

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/canureal/thunder-daw/releases/download/v0.2.1/thunder-daw-installer.sh | sh

Windows PowerShell:

irm https://github.com/canureal/thunder-daw/releases/download/v0.2.1/thunder-daw-installer.ps1 | iex
