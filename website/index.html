Make music

Piano rollnotes, velocity, ghost notes, scales, chord stamps, quantize / humanize / strum / arp
Playlist8 patterns as per-bar clips, Song / Pattern modes
Instruments8-voice poly synths, synthesized drum kit, WAV/MP3 sampler + browser
Mixer & FXdelay + reverb sends, soft-clipped master, scope, peak meter
Automationvolume + filter-cutoff lanes, no-dropout live control
Song toolsJSON save/load, WAV mixdown, MIDI export, metronome, swing, tap tempo

Run it

sudo apt install libasound2-dev libx11-dev libxkbcommon-dev libwayland-dev libegl-dev libgl-dev
cargo run --release

…or grab the Linux binary from Releases.
