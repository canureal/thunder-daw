⚡ thunder-daw

A tiny FL Studio-style step-sequencer DAW in Rust.

Run it

sudo apt install libasound2-dev libx11-dev libxkbcommon-dev libwayland-dev libegl-dev libgl-dev
cargo run --release

Features

  • 6-channel × 16-step sequencer with mute / solo
  • Per-channel fundsp editor: wave, base note, cutoff, Q, ADSR
  • Mixer with equal-power pan, master bus with soft clip
  • Live 2-octave piano on a dedicated saw voice
  • Master scope + peak meter
  • Headless self-test: cargo run -- --offline-test

Status
