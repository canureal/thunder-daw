thunder-daw

A small FL Studio-style DAW written in Rust. Step sequencer, piano roll, playlist, mixer. Nothing hosted, no account, files stay on your disk.

What it does

Piano rolladd, drag and resize notes. Velocity lane, ghost notes, scales, chord stamps. Quantize, humanize, strum, arpeggiate.
Playlisteight patterns placed as one-bar clips. Play the arrangement or loop a single pattern.
Instrumentspolyphonic synths with eight voices each, a synthesized drum kit, and a sampler that loads WAV, MP3 and OGG files.
Mixer and FXper-channel delay and reverb sends, soft-clipped master bus, scope and peak meter.
Automationvolume and filter-cutoff lanes. The cutoff moves live with no audio dropouts.
Song toolssave and load projects as JSON, export a WAV mixdown or a MIDI file. Metronome, swing, tap tempo.

Install

Linux or macOS, paste this in a terminal:

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/canureal/thunder-daw/releases/latest/download/thunder-daw-installer.sh | sh

Windows, in PowerShell:

irm https://github.com/canureal/thunder-daw/releases/latest/download/thunder-daw-installer.ps1 | iex

Or build from source. Linux needs the audio and windowing headers first:

git clone https://github.com/canureal/thunder-daw.git
cd thunder-daw
sudo apt install libasound2-dev libx11-dev libxkbcommon-dev libwayland-dev libegl-dev libgl-dev
cargo run --release

Status and limits

CI runs fmt, clippy, unit tests and a headless audio self-test on every push. Dependabot keeps dependencies current. Known limits: eight fixed channels, no plugin hosting, no audio recording. The docs page lists all of it.
