Architecture

Mirrors real FL Studio: global channels → patterns of notes → playlist arrangement → mixer. One Arc<Mutex<AppState>> is shared between the cpal audio thread and the egui thread.

ModuleOwns
song.rsChannels, patterns, notes, automation, save/load, edit tools + unit tests
engine.rsfundsp voice pools (8/channel), kit + sampler playback, delay/reverb, tick scheduler
export.rsWAV mixdown (hound), hand-rolled SMF type-0 MIDI writer
ui.rsTransport, rack, piano roll, playlist, mixer, browser

Each synth voice is a live fundsp graph:

((var(pitch) >> osc | var(cutoff) | dc(Q)) >> lowpass
  * (var(gate) >> adsr_live)) >> pan

Pitch/gate/cutoff ride lock-free Shared vars, so automation moves the filter with zero graph rebuilds. The scheduler runs on an integer sample clock (no float drift), with swing applied to off-beat 16ths.
