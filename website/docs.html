Architecture

One Arc<Mutex<AudioState>> shared between the cpal audio thread and the egui UI thread. Each channel owns a fundsp voice:

(var(pitch) >> osc >> lowpass_hz(cut, q))
  * (var(gate) >> adsr_live(a, d, s, r))
  >> pan(0.0)

Lock-free Shared vars carry pitch/gate into the realtime graph. The cpal callback advances the 16th-note clock (sr * 60 / bpm / 4 samples per step) and schedules gate-off countdowns per voice. Mixing (volume, equal-power pan, tanh soft clip) and the scope buffer happen in plain Rust after the fundsp ticks.

Controls

  • Transport: Play/Stop, Reset, BPM 60–200, Master
  • Channel rack: click steps to toggle, M = mute, S = solo
  • Editor: wave, base note (MIDI 21–108), cutoff, Q, ADSR — rebuilds the fundsp graph live
  • Piano: triggers the dedicated live voice for ~0.4 s
