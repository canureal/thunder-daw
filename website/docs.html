Architecture

The layout copies FL Studio: global channels hold the instruments, patterns hold notes, the playlist orders patterns into a song, and the mixer sets levels. One shared struct connects the audio thread (cpal) and the interface thread (egui).

ModuleJob
song.rsChannels, patterns, notes, automation, save/load, edit tools, unit tests
engine.rsfundsp voice pools (8 per channel), kit and sampler playback, delay/reverb, tick scheduler
export.rsWAV mixdown, hand-written type-0 MIDI writer
ui.rsTransport, rack, piano roll, playlist, mixer, browser

Each synth voice is one fundsp graph:

((var(pitch) >> osc | var(cutoff) | dc(Q)) >> lowpass
  * (var(gate) >> adsr_live)) >> pan

Pitch, gate and cutoff travel through lock-free shared variables, so automation moves the filter without rebuilding anything. The scheduler counts whole samples, which keeps timing from drifting.

Controls

PanelControls
TransportPlay, stop, reset. Song or pattern mode. BPM with tap tempo, swing, metronome, loop, master volume. Position reads bar:beat:tick.
Channel rackSixteen step buttons per channel. Mute, solo, wave or kit picker, base note, preview button.
Piano rollClick adds a note, drag moves it, the right edge resizes it. Right-click or Delete removes it. Velocity and automation lanes sit below.
PlaylistOne pattern clip per bar. Reorder, delete, add bars.
MixerVolume, pan, cutoff, delay and reverb sends per channel. Master delay time and mix, reverb mix.
BrowserLists sample folders. Preview a file, load it into the selected channel, or paste a path.

Status

  • Dependencies are current: cpal 0.18, eframe/egui 0.36, fundsp 0.23, Rust edition 2024
  • CI checks formatting, lints, unit tests and a headless audio render
  • Tagged releases ship Linux, Windows and macOS builds with a changelog
  • This site rebuilds from website/ on every push to main
  • The audio thread drops to silence if it misses a lock. Fine for practice, not for stage use
  • Eight fixed channels. No plugin hosting, no audio recording, no MIDI hardware
